# Custom art

This module ships with **no bundled artwork** — by default, group tokens use
Foundry's built-in core icons.

To use your own **human-made** art for group tokens and portraits, either:

1. **Settings (recommended):** Configure Settings → Module Settings → Nimble
   Party, and set the file paths for Party portrait, Party token, Enemy
   portrait, and Enemy token; or
2. Drop image files into this `assets/` folder and point the settings above at
   them (e.g. `modules/nimble-party/assets/my-party.png`).

Note: artwork distributed through the official Foundry package listing must be
human-created. See https://foundryvtt.com/article/ai-policy/.
